# Kanban icon sources

Selected from the Lucide family supported by the Morphicons playground: https://www.morphicons.com/.

- Kanban: task board
- Inbox: incoming documents
- UsersRound: team members
- Scale: insurance plan comparison
- Bookmark / BookmarkCheck: personal bookmark state, animated with Morphicons

Lucide 1.43.0 (ISC) provides icon geometry; Morphicons 1.7.1 (MIT) provides the bookmark transition. License texts are included alongside this file. Assets are bundled locally; no icon CDN or runtime third-party requests. The animation respects prefers-reduced-motion.
