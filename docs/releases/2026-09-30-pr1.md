## Application rollback

Previous image: `team-kanban-postgres:20260930-login`, retained on AWS.

Deployment configuration backup: `/opt/deployments/kanban-pr1-9b454d5/`.

Run on the AWS host:

```bash
cd /opt/projects/kanban
sudo docker compose stop worker
sudo cp -p /opt/deployments/kanban-pr1-9b454d5/compose.override.yaml ./compose.override.yaml
sudo docker compose up -d --no-deps --wait --wait-timeout 180 web
sudo docker compose up -d --no-deps worker
```

Keep the current production database and attachments when rolling back the application image. Do not restore the old PGlite snapshot over current PostgreSQL data.
