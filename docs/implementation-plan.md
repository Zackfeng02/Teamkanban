# 当前实施计划

## 路线更新

用户在机器人单聊逐条转发文字和图片测试通过后要求继续开发，并指定 AI 为 DeepSeek V4.1 Flash。本轮按该单聊路线实现，不再等待未开通的会话存档来开发这条独立入口。

原始合并转发需求仍未满足，原存档验收矩阵仍未完成。保留限制，不将单聊逐条转发称为合并记录解析成功。

## 本轮交付

1. Next.js 中文桌面看板和手机纵向列表。
2. 邀请登录、成员权限、一次性企微身份绑定。
3. 单聊接入、消息去重、显式资料归组、图片私有存储与重试。
4. 可配置 V4.1 Flash 适配层、模型身份校验、持久化队列、人工确认拆分建卡。
5. 任务更新、并发版本、评论及变更记录、归档恢复。
6. 自动化、HTTP 和浏览器验证。

## 外部依赖

- 确认 AI 服务商、准确模型 ID、密钥及视觉接口能力，完成虚构资料真实调用。
- 正式团队首次管理员接受本地邀请码，绑定实际微信身份后实测完整新应用链路。
- 确定生产部署区域、对象存储、PostgreSQL、备份恢复和保留期限。
- 完成 iOS/Android 真机转发与网页确认流程；浏览器模拟尺寸不等于真机验收。

## 当前实现取舍

本地使用持久化 PGlite，生产通过 DATABASE_URL 切换 PostgreSQL。工作进程调用网页内部 API，避免多个进程并发打开本地数据库。每个团队的业务状态以 JSONB 聚合记录保存，事务行锁配合任务版本避免静默覆盖。

账号先采用一次性邀请和密码；普通登录只需账号和密码，首次注册时由邀请码绑定团队。密码找回采用本机管理员一次性恢复码，暂未实现邮件验证码。机器人不自动回复，只在网页提醒。未连接机器人时不能收到新资料；离线历史回放尚无已验证接口保证。
