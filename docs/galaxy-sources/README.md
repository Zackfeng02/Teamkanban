# Galaxy UI demo

Route: `/design-demo`. Self-contained React state and mock data only; no API calls, writes, or changes to production Kanban styles. Refresh resets the demo.

Six selected sources: andrew-demchenk0's splendid-impala-69 sliding button; alexruix's slippery-frog-10 search input and cold-cat-38 stacked card; Galahhad's mighty-warthog-42 bookmark, heavy-dog-14 switch and old-falcon-43 popup. All adapted in `src/app/design-demo/demo.css`; originals in this folder retain creator comments. MIT license is included as LICENSE. Repository: https://github.com/uiverse-io/galaxy

The new-newt-64 card and perfect-cheetah-72 theme popup were inspected but not selected: hidden card content and a theme selector do not improve this task workflow.

Visual direction: existing sage/cream palette, quiet borders, compact task metadata, interactions only on demand. Reduced-motion users get static feedback. Demo includes board search, personal/saved filters, bookmarks, task creation/status changes, density, inbox conversion, team overview, and insurance-plan selection.
